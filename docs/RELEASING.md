# 发布前清单

项目仓库名为 `boox-weread-toolkit`，显示名“文石微信读书极简工具箱”。以下清单适用于首次发布和后续更新。

1. 用新版 APK 在真实 Leaf2 P 上完成 `VALIDATION.md` 中的回归项目；更新支持范围和结果日期。
2. 用真实设备验证电脑端选择、取消、恢复流程。只选自己明确不需要的项目；不自动套用整份清单。
3. 使用自己的长期发布签名生成非 debuggable APK，检查签名并记录证书 SHA-256 指纹。保管私钥，不随仓库或附件发布。
4. 若需安装到以前的个人设备，先看恢复指南中的签名兼容说明。
5. 检查公开文件不含本机绝对路径、设备标识、账号、书籍截图、原始日志、SDK、签名私钥或恢复记录。
6. 在 GitHub 创建仓库，提交源码、文档、许可证与测试；创建预发布 `v0.1.0`。仓库简介可用 README 第一段。
7. Release 附正式签名 APK、SHA256SUMS、主要变化、支持设备和已知问题。测试 APK 如另附，应明确标为测试用途。

完成实机测试前也可公开源码预发布，但应保留“新版待实机回归”的说明。

本项目不分发文石固件、系统 APK、微信读书 APK 或第三方 SDK 工具。品牌名称用于说明兼容用途；未使用第三方品牌图标。
