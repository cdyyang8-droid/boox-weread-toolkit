# 支持范围

| 项目 | 已有证据 | 本次整理版状态 |
| --- | --- | --- |
| BOOX Leaf2 P / Android 11 / 文石 4.0.2 | 2026-10-22 个人配置实测 | 新版待实机回归 |
| 微信读书墨水屏版 | 旧版打开、阅读、联网推荐、重启验证 | 保留包名与启动逻辑 |
| 微信读书普通版 | 无既有实测 | 新增备用包名，待验证 |
| 专用首页 | 旧版单次 HOME 跳阅读、双次 HOME 开控制页及恢复通过 | 新增模式切换，待实机验证 |
| 25 项停用清单 | 同一设备两轮停用状态及核心功能复查 | 已泛化为逐项选择，电脑端使用模拟设备测试 |
| Android 8/9 | 无既有实测 | 提供版本判断，最低 API 26；待验证 |
| Windows / Linux | 无既有实测 | Python 标准库实现；待验证 |

旧版实测不是对新版的完整验证。重启及联网阅读通过不代表重新登录、扫码登录、付费、听书或双向进度同步均已通过；这些功能和长期续航尚无完整测试。

首页仍依赖原系统和用户已安装的微信读书。开机标志、原厂加载过程、阅读器按钮行为由设备系统决定。原厂冻结策略可能阻止首页正常运行，需手动解除冻结。

当前 targetSdk 为 30，保留原型行为，面向侧载测试，不满足 Google Play 新应用上架要求。后续提高 targetSdk 时需要重新核验角色、包可见性及导航行为。
