# 恢复指南

## 恢复应用和服务

运行 `python3 tools/boox_tool.py restore backups/实际文件名.json`。工具要求设备序列号与固件指纹匹配，再展示要恢复的项目，输入 `YES` 后按每项原始状态恢复。

原始状态可能是默认、显式启用或不同的停用状态。工具保存这些差别，不把所有项统一改成启用。原已停用的包不会被本工具再次修改。

如果停用到一半失败，原状态已在第一项修改前全部写入记录。即使最后一项命令执行成功但返回失败，也可按记录恢复。恢复命令本身中途失败后，可以再次运行同一条恢复命令；已恢复的项会跳过。

不要删除恢复记录，不要修改其中设备标识或包名。最新一次操作先恢复，避免覆盖后续选择。工具检测到与本次操作不一致的状态会停止，此时请核对是否有其他工具或系统更新修改了设置。

## 恢复文石默认首页

在本应用设置中点击“恢复原来的文石首页”并确认。它先尝试打开原厂桌面，随后停用本应用 HOME 组件；“阅读器设置”入口仍保留，可重新开启默认首页。

电脑端可运行 `python3 tools/boox_tool.py restore-home`，会先验证 `com.onyx/.StartupActivity` 能解析为可用桌面，再切换默认 HOME 并核对。不会改动服务清单。

不同固件可能使用其他原厂桌面包名。若工具找不到此组件，请从原厂系统的默认应用设置中选择桌面；不要停用或删除原厂桌面。

## 升级与签名

刷固件或 OTA 前，建议先用记录恢复服务，再升级并重新检查清单。固件指纹变化后，工具拒绝自动套用旧记录，需要人工按新固件核对。

旧的个人版与新公开版使用相同包名 `local.weread.home`，签名可能不同。Android 会拒绝不同签名的覆盖安装。请先恢复原厂首页，再卸载旧首页并安装新 APK；卸载首页会重置其模式偏好，不会删除微信读书中的书籍。勿卸载微信读书。

## 记录丢失

工具无法从当前停用状态推断修改前是否为默认或显式启用。请先在原厂应用管理中核对，或由熟悉 ADB 的用户逐项恢复。不要用未知来源的一键恢复脚本批量开启系统包。

状态记录不包含应用数据或书籍，不能用于还原数据删除。
