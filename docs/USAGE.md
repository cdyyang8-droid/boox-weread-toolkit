# 安装与使用

## 准备

电脑安装 Python 3.9+ 和官方 Platform Tools，把 `adb` 加入 PATH。运行 `adb devices`，设备应显示为 `device`；`unauthorized` 表示需要在阅读器屏幕上确认 USB 调试授权。本项目不分发 ADB、JDK 或 Android SDK。

打开 USB 调试的方法因固件而异，请按原厂开发者选项说明操作。使用可传输数据的数据线。

## 首页应用

1. 安装自行编译或从本项目发布附件下载的 APK，也可用 `adb install app.apk`。
2. 应用名称为“文石微信读书极简首页”，应用列表中的设置入口名为“阅读器设置”。
3. 点击“设为默认首页”。Android 10+ 请求 HOME 角色；Android 8/9 尝试打开系统默认首页设置。
4. 默认是极简首页。开启“微信读书专用模式”后，下次返回首页自动跳转微信读书。真正的开机自动进入取决于原厂系统是否启动默认 HOME。
5. 4 秒内连续执行两次“返回首页”打开控制页。这不是微信读书中的“返回上一页”。进程被系统回收后，计时会重置。
6. 文石桌面入口用于原厂墨水屏、前光等设置，不会改变默认首页。恢复按钮才会退出专用首页。

微信读书无法启动时保留控制页。需要更改字体、刷新模式、侧键、前光等，请使用微信读书或文石原厂设置；本版不代改这些参数。

## 服务选择

运行 `python3 tools/boox_tool.py select`，按编号选择，每项显示包名和影响。Google 服务单独标注，词典与快捷传书也是独立选项。直接回车不选任何项。

预览会说明实际需要停用哪些包，输入 `YES` 后才执行。工具只操作主用户 0 的清单包，不卸载、不清数据。执行命令为 `pm disable-user --user 0`。

服务可能相互依赖；Google 分组仅提供分类，不是自动依赖分析。希望完整使用 Google 的用户应保留整组。部分 Google 包名在其他固件中可能不同，工具只处理精确匹配的已安装包。

执行前自动生成 `backups/*.json`，含设备序列号、固件指纹和每个包的原始启用状态，保存在电脑本地。请保留并自行备份，勿上传到公开仓库。不要同时用多个工具修改同一台设备；恢复请按操作时间倒序。

只读命令：`list`、`status`、`select --dry-run`。除 `list` 外都需要设备连接。工具不主动收集日志、账号或阅读内容。

## 多设备与特殊路径

全局选项放在子命令前：

```sh
python3 tools/boox_tool.py --adb "/path with spaces/adb" --serial DEVICE_SERIAL status
python3 tools/boox_tool.py --backup-dir "/path/to/private-backups" select
```

电脑工具会检查制造商/品牌包含 BOOX 或 ONYX，拒绝操作其他品牌。型号与固件差异仍需用户核对；检查品牌不能证明清单适合所有型号。
