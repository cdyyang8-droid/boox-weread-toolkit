## 实机回归步骤

1. 记录型号、Android、固件及微信读书版本。先确认原厂桌面可用。
2. 安装测试 APK，设为默认首页。测试极简模式各入口。
3. 切到专用模式，测试单次 HOME、4 秒内两次 HOME、重启。
4. 测试阅读应用不可用时是否仍可访问设置；不要删除账号或书籍来做此测试。
5. 用页面恢复原厂首页，再从应用设置入口重新启用。
6. 电脑端 status、dry-run，随后只选择一个明确不需要的项目，验证停用与恢复。记录应包含原状态且最终状态一致。
7. 重复取消、记录恢复与重新运行，确认没有额外改动。
8. 实际使用常用登录、下载、同步和阅读功能，记录结果及限制。
